# 章节输入模板

从本地 Markdown 文件读取章节时的格式约定。

## 文件命名
```
第<N>章.md
```
例如：`第8章.md`、`第16章.md`

## 内容格式
Markdown 文件的第一行 `# 第N章 标题` 作为章节标题，
其余内容作为正文。正文中的自然换行保留。

## 示例

```markdown
# 第8章 标题

正文第一段...

对话内容...

...
```

## 自动提取规则

1. 标题 = Markdown 文件第一行去掉 `# ` 前缀
2. 正文 = 从第二行到文件末尾
3. 文件路径 = 相对于 `~/novels/books/《书名》/01-正文存稿/`
