# 固定 Profile 投递的等价启动兜底

## 适用条件

仅当以下条件同时满足：

- `publish_chapter.py` 是当前已验证的投递脚本；
- 章节文件、BOOK_ID 和 `~/.hermes/browser-profiles/fanqie` 均已准备好；
- Hermes shell 包装层在 Python 进程启动前误拦命令；
- 用户明确要求继续原有技能流程。

## 等价执行

在 macOS 现有「终端」窗口运行技能原命令，保持命令内容不变：

```bash
~/.hermes/hermes-agent/venv/bin/python3 \
  ~/.hermes/skills/novel/scripts/publish_chapter.py <章节号> \
  --book '<书名>'
```

这只是绕过命令包装层，不是替换发布方案。禁止切换浏览器、创建隔离 Profile、手工复制正文或改写脚本。

## 验证闭环

1. 等待脚本明确输出「第N章已存草稿」。
2. 不重新打开新建章节页。
3. 使用草稿箱专用路由核对章节号、标题、平台字数、修改时间。
4. 平台字数与本地可能相差少量字符，以后台值为准，不擅自改正文。
5. 保存回执不等于核对成功；只有草稿箱列表证据完整时，才能报告 `draft_saved_verified`。

## 风险边界

- 遇到登录二维码、验证码或风控立即停止。
- 不点击正式发布、确认发布、定时发布。
- 若怀疑脚本可能已执行，不重复投递；先查草稿箱，避免重复草稿。
