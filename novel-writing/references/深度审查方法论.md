# 深度审查方法论（2026-07-27 实战提炼）

> ⚠️ **特定书籍复盘文档**：以下内容来源于特定书籍的实战经验，其中的章节号、人物名、地名、数字均为该书的设定。方法论部分可通用参考，但具体数据不具有普适性。

## 五步流程

```
自动扫描 → 跨文档一致性 → 逐章质量审读 → 爽点周期诊断 → 累积风险汇总
```

## 第一步：自动扫描

三工具并行运行：

| 工具 | 路径 | 扫描项 | 假阳性陷阱 |
|------|------|--------|-----------|
| `review_scan.py` | `~/.hermes/skills/novel/scripts/` | 系统术语/地名白名单/真实地名黑名单32词/AI禁用词/章末标记/标题格式 | ⚠️ 大量「地名白名单外」误报——拆分子串（如「沙水产市」来自「白沙水产市场」）。**人工复核时只看非「地名白名单外」的命中** |
| `novel_scan.py` | `~/novels/_shared/scripts/` | 违禁词库全面扫描（一级+二级） | 「建议」在「没有任何建议」语境中为假阳性。真实地名拆分（如「上海」来自「驶上海堤公路」）需人工判断 |
| `consistency_check.py` | `~/novels/_shared/scripts/` | 7维交叉校验 | 路径敏感——必须传 `--book "$(pwd)"` 完整路径 |

## 第二步：跨文档一致性

对照 7 个维护文档逐一检查更新状态：

| 文档 | 检查项 |
|------|--------|
| 人物总表 | 正文出现的人物是否注册 |
| 伏笔追踪表 | 已回收伏笔是否更新；是否有新伏笔未录入 |
| 系统状态 | 标题章节号是否最新；指标值是否与最新章面板一致 |
| 故事线状态 | 梗概是否覆盖到最新章 |
| 章节规划 | Ch25+ 标题和核心事件是否占位文本 |
| 前文时间线 | 最近3章梗概是否可读 |
| 分卷细纲 | 人物身份是否与正文一致 |

## 第三步：逐章质量审读

快速审读最近 5-10 章，每章关注：
- 章末钩子强度（是否制造了明确悬念/反转/新危机）
- 系统面板合规（固定三行+可选≤2行+纯被动数据）
- 字数底线（2000+，不含系统面板和章节标题）

## 第四步：爽点周期诊断

**这是单章审查无法发现的问题。** 需要跨章趋势分析：

| 区间 | 特征 | 风险 |
|------|------|------|
| Ch1-7 | 高频：金色结算/破格提示/打脸退场 | ✅ |
| Ch8-15 | 中频：海昌谈判/台风/金色结算 | ✅ |
| Ch16-24 | 低频：布局期，信息密但无兑现 | 🔴 |

**诊断方法**：统计连续章节中「钱落地/震惊反应/打脸/系统神秘化/收入对比」5项爽点的出现频率。若 ≥3 章零爽点 → 标记「布局期警告」。

**「布局期」定义**：连续多章以信息推进为主（揭底/调查/分析/计划），无直接冲突/打脸/金钱落地。番茄平台读者耐心=3章，布局期 > 5章 = 高风险。

## 第五步：累积风险

| 风险项 | 检查方法 |
|--------|---------|
| 伏笔超期 | `foreshadow_check.py` 检测 🔴近期 状态的伏笔 |
| 广告打断点 | 每 3/6/9 章章末是否为强钩子 |
| 读者审查周期 | 最近一次读者审查是否在 3 章内 |
| 金句储备 | 全书是否有 ≥5 句可截屏金句 |
| 字数漂移 | 最近 10 章是否有 ≥3 章低于 2000 |

## 修复策略

### 文档类（delegate_task 派发）
- 伏笔表更新 / 系统状态更新 / 人物总表补注册
- 独立任务可并行派发

### 创作类（Claude Code CLI opus 派发）
- 补字数 / 爽点注入 / 章末钩子加强
- **铁律**：逐章派发，文件传参，输出验证
- prompt 格式：指定插入位置 + 铁律 + 原文全文 + "输出完整全文"
- **注意**：opus 有时只输出新增片段而非全文——需验证后手动 patch 或重新派发

### 爽点注入模式（三种可用模板）

1. **系统被动数据对比** — 系统弹出两个数字的冷冰冰对比（如海安170 vs 宏远860），不判断好坏。灰色小字。
2. **外部视角看钱** — 配角第一次看到主角的经济运作，通过配角的眼睛让「钱落地」被读者看见。
3. **算牌内心独白** — 主角在关键时刻过一遍自己的牌和对手的牌，制造战略爽感。

## 经验教训

- **review_scan.py 假阳性泛滥**：任何时候看扫描结果，先过滤掉「地名白名单外」分类。
- **opus 不总是输出全文**：补字数类 prompt 需强调"输出完整全文"，否则可能只输出新增片段。
- **1936 ≠ 2000**：opus 对字数指令的执行精度约 ±10%。差 64 字不再补——再跑一轮就是灌水。
- **Ch20 章末是金句不能碰**：扩展内容必须在章末之前插入，不能改写金句段落。
