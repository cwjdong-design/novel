> 通过 Hermes 浏览器工具半自动操作番茄作家后台发布章节。

## 入口地址

- 正确 URL：`https://fanqienovel.com/writer`
- ❌ `writer.fanqienovel.com` 解析不了
- ❌ `author.fanqienovel.com` 解析不了
- 正确路径：从 `fanqienovel.com` 首页 → 导航栏「作家专区」→ 跳转到 `/writer`

## 登录方式

| 方式 | 可行性 | 说明 |
|------|--------|------|
| 短信验证码 | ⚠️ 需人工 | 输入手机号后触发**滑块验证码**，headless 浏览器无法通过 |
| 扫码登录 | ✅ 推荐 | 页面展示二维码，用手机番茄小说/抖音 APP 扫码 |
| 密码登录 | 待测试 | 页面有「密码登录」按钮，需要先绑定密码 |

### 短信验证码流程（受阻于滑块）

```
输入手机号 → 勾选协议 → 点击"获取验证码" → ❌ 滑块验证码 → 阻塞
```

滑块验证码在 `<iframe>` 中渲染，headless 浏览器无法完成拖拽。**此路不通。**

### 扫码登录流程（推荐）

```
切换到扫码登录 → 页面展示二维码 → 用户手机扫码 → 页面自动跳转后台
```

截图二维码后通过 `MEDIA:` 发给用户扫码。扫码成功后浏览器会自动跳转到作家后台首页。

## 浏览器工具选择

| 工具 | 适用性 | 原因 |
|------|--------|------|
| `browser_*`（Hermes 内置） | ✅ 首选 | headless Chromium，能正常导航、点击、输入 |
| `computer_use` + Chrome | ❌ 不适用 | macOS Chrome 的 AX 树只暴露菜单栏，不暴露网页内容 |

`computer_use` 在 macOS 上对 Chrome 无效——capture 返回的 AX 树只有 `AXMenuBar`/`AXMenuItem`，没有 `AXWebArea`/`AXTextField`/`AXButton` 等网页元素。这是 macOS 辅助功能 API 的限制，不是配置问题。
