# 作者声音DNA定义

> 来源：2026-08-07 用户反馈。写到Ch46时用户指出：「写作行文风格，还有写作习惯，作者的特别习惯，是不是没有？每个网文作者都有他的习惯和口头禅，你有了吗？你设定了吗？写出来还是很AI味。」
>
> 书配置里的「直接、不煽情、冷幽默、冷感叙述」只是**温度**描述，不是**作者DNA**。Claude Code 没有具体的风格锚点，默认用AI通用文学腔——均匀句长、工整段落、正确但无个性的比喻。结果是「技术上合格但没有辨识度」。

## 问题诊断

AI生成的正文有5个共性特征导致「AI味」：

| AI特征 | 具体表现 | 读者感受 |
|--------|---------|---------|
| 句式均匀 | 每句15-25字，长度接近 | 像新闻稿，没有节奏 |
| 比喻正确但无个性 | "像一尊雕塑""像被风吹散的烟雾" | 正确但谁都能写 |
| 段落结构工整 | 起承转合完整，过渡均匀 | 缺乏意外感 |
| 叙事视角模糊 | 有时贴近MC内心，有时跳到旁观 | 读者无法代入 |
| 缺少标志性用词 | 没有反复出现的口头禅/偏好词 | 作者面孔模糊 |

## 作者DNA定义模板（新书必填，加入书配置.md）

```markdown
## 作者声音DNA

### 句式节奏
- 偏好句长：<短句为主/长短交替/中长句为主>
- 节奏特征：<例：三短一长/急促-放缓-急促/平静中突然断句>
- 禁止句式：<例：不写超过40字的长句/不写排比>

### 标志性用词
- MC口头禅：<例：「慢慢来」「不急这一时」>
- 叙述偏好词：<反复使用的特定词，如「干脆」「利索」「闷」>
- 禁止用词：<AI味的词，如「仿佛」「宛如」「不禁」「竟然」（限定叙述段）>

### 比喻习惯
- 偏好意象域：<例：海/鱼/船/天气（渔民出身）/城市/网络/游戏（都市青年）>
- 禁止意象域：<例：不写花的比喻/不用诗意象>

### 叙事视角
- 视角距离：<极贴MC内心/中等距离旁观/冷记录>
- 视角一致性：<全书不变/按场景切换>
- 内心独白频率：<从不写内心/每章1-2句/允许短段内心>

### 对话标记习惯
- 标记方式：<几乎不用「他说」/只用动作带出/偶尔用「他道」>
- 动作描写频率：<每句对话都带动作/每3句带1次/只关键时刻带>

### 氛围底色
- 默认情绪：<冷/干/燥/湿/闷>
- 环境描写密度：<极简（只写关键1-2个细节）/中等（每场景3-5个细节）/浓密>
- 时间感：<紧凑（事件密集）/松弛（留白多）/交替>
```

## 去AI味检查清单（REVIEW阶段附加）

在REVIEW爽点5项之后，附加以下AI味扫描：

```
[ ] 句式均匀度：连续5句字数差<5字？→ 🔴 打破节奏（插入短句/断句）
[ ] 比喻辨识度：本章的比喻换到别的书也能用？→ ⚠️ 需替换为该作者DNA意象域的比喻
[ ] 叙述视角漂移：同一段内视角从MC内心跳到旁观？→ 🔴 锁定视角
[ ] AI禁用词扫描：搜索「仿佛」「宛如」「不禁」「竟然」「不由得」「一股」「涌上」→ 命中即改
[ ] 标志性用词出现率：本章MC口头禅/偏好词是否出现至少1次？→ ⚠️ 需补
```

## DRAFT prompt 注入

骨架模式 prompt 的3条铁律之外，追加作者DNA片段（从书配置.md的「作者声音DNA」区块提取）：

```
【作者DNA（从书配置读取，必须遵循）】
- 句式：<具体规则>
- 标志性用词：<MC口头禅+叙述偏好词>
- 比喻意象域：<只准用的意象>
- 禁止用词：<AI味词表>
```

## 已有作品风格逆向分析（从正文中提取DNA）

当书已经写了多章但未定义DNA时，可对已有正文做完整逆向分析。以下为经过实战验证的分析流程（2026-08-07，《重生海安人口越多我越有钱》48章分析）。

### 步骤1：抽样

取6-8章正文，覆盖不同阶段（开头/前期/中期/后期/卷尾）。建议取 Ch1、Ch5、Ch10、Ch20、Ch30、Ch40、Ch44、Ch48 这样的分布。

### 步骤2：6维度统计分析（用 execute_code 跑 Python）

#### 2a. 句式节奏
- 按中文句号/感叹号/问号/换行分句，去掉【系统面板】内容和标题行
- 统计：超短句(≤4字)、短句(5-8字)、中句(9-20字)、长句(21-35字)、超长句(>35字)各占比
- 计算：平均句长、中位句长、段落形态（单行段占比）
- **关键指标**：短句+超短句合计占比（>40%说明短句为主）；连续相似句长检测（AI均匀度诊断）
- 输出前40句的长度序列，用于人工识别节奏模式

#### 2b. 标志性用词
- **AI味词扫描**（全量）：搜索「仿佛」「宛如」「不禁」「竟然」「不由得」「一股」「涌上」「似乎」「犹如」——统计出现次数，找到上下文例句
- **否定式标记统计**：「没说话」「没看」「没动」「没回头」「没回答」「没出声」「没应」——这是MC沉默反应的指纹
- **动作偏好词统计**：「蹲」「攥」「走了」「停了」等高频动词
- **触感词统计**：「冷」「凉」「硬」「热」「湿」「粗」——氛围底色词
- **方言标记统计**：按书配置的方言类型统计标记词频率（粤语：系/唔/咗/嘅/返等）
- **MC台词分析**：提取MC对话，统计台词长度分布（平均/中位/≤10字占比），列出高频短回应

#### 2c. 比喻习惯
- 正则提取所有含「像」的句子，过滤出实际明喻（像X一样/似的/般）
- **分意象域归类**（4大域）：
  1. 日常平淡行为类比（"像在记账""像在报价"）——降格类比
  2. 旧物件/机械（"像一台扫描仪""像一盏很小的灯"）
  3. 海港/劳作/有机体（"像退潮""像一头牲畜"）——按书的题材调整
  4. 身体/触感（"像父亲的手""像树皮"）
- 统计各域占比，识别核心比喻策略（如此书的"降格类比"——越紧张比喻越平淡）
- 检查引导词偏好（只用「像」vs混用「如/犹/若」）

#### 2d. 叙事视角
- 统计MC名字频率、「他」指代MC频率
- 统计MC内心可触达时刻（记得/知道/想/想起/盯着/脑子里）——区分行为层 vs 深层内心
- **POV偏移检测**：搜索其他角色的内心可触达词（冯志强想/魏国栋看），统计频率和访问深度
- **关键诊断**：是否存在POV漂移（同段内视角跳跃）；MC情绪是直接描写还是通过行动表达

#### 2e. 对话标记习惯
- 统计总对话行数（含「的行数）
- 分类归因方式并统计占比：
  - 无标记裸引语（整行只有「…」）
  - 引语→描写（「…」后跟动作/状态）
  - 动作→引语（X做了什么，「…」）
  - 引语→X说/道
- 明确「X说」类标记总数及占比

#### 2f. 氛围底色
- 时间词频率统计（凌晨/早上/中午/下午/傍晚/晚上/天亮/天黑）
- 环境词统计（海风/风/太阳/月光/光/暗/亮/灰）
- 声音词统计（响/声/嗡/轰/突突/嘎吱/啪）
- 破折号(——)和省略号(……)使用频率
- 章末模式分析：取多章最后2-3句，归类收尾类型（动作完结/判断句/意象/悬念/留白）

### 步骤3：AI味诊断（5项清单）

| 检查项 | 判定标准 | 通过条件 |
|--------|---------|---------|
| 句式均匀度 | 连续5句字数差 | 差值>5字为通过；短句占比>40%为通过 |
| 比喻辨识度 | 比喻是否可替换到其他书 | 有独家意象域（如此书的系统面板比喻）为通过 |
| 视角漂移 | 同段内视角是否跳跃 | 全书POV一致或偏移仅在反派外部观察为通过 |
| AI禁用词 | 仿佛/宛如/不禁/竟然等 | 近乎零出现为通过 |
| 标志性用词 | MC口头禅/偏好词频率 | 每章出现≥1次高频特征词为通过 |

### 步骤4：输出

生成「## 作者声音DNA」markdown区块（可直接粘贴到书配置.md），包含：
- 6维度的DNA规则（从数据提取，标注✅已有正文特征）
- 补充维度（场景结构惯例：场景切换方式、系统面板锚点、数字密度、章末钩子分类）
- 待用户确认的建议项（⚠️标注，如暖色段落限额、方言例外处理等）

### 实战要点

- **UTF-8文件可能被误判为binary**：章节.md文件可能被 `read_file` 拒绝（误判为binary）。用 `terminal` 执行 `cat` 读取，或用 `execute_code` 的 `open(path, 'r', encoding='utf-8')` 读取。
- **全量统计+样本深读结合**：8章样本深度阅读（理解风格意图），48章全量统计（获取词频数据）。两者不可替代。
- **比喻分类是人工活**：正则只能提取含「像」的句子，意象域归类需要人工判断。
- **输出不是新增约束**：对于已有清晰风格的正文，DNA区块是固化已有特征，不是新增限制。
