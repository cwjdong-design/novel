# 布局期爽点衰减检测

> ⚠️ **特定书籍复盘文档**：以下内容来源于特定书籍的实战经验，其中的章节号、人物名、地名、数字均为该书的设定。方法论部分可通用参考，但具体数据不具有普适性。

> 2026-07-27 深度审查发现。Ch16-24 连续 9 章布局期，爽点密度降至危险水平。

## 现象

「布局期」= 揭开主要对手后，连续 ≥ 4 章处于信息搜集/策略准备，无直接冲突/打脸/金色结算。

Ch16-24 实况：揭开宏远 → 信息搜集 → 人情章 → 养殖数据。零打脸、零金色结算。字数从 2,313 跌至 1,424。

## 阈值

| 信号 | 阈值 | 
|------|------|
| 连续无打脸 | ≥ 4 章 → 🔴 |
| 连续无金色结算 | ≥ 5 章 → 🔴 |
| 章末钩子覆盖 | < 2/3 章 → 🔴 |
| 爽点密度 | < 1 个/章 → ⚠️ |
| 字数连续下降 | ≥ 2 章 < 2,000 → 🔴 |

## 对策

- 布局期每 2-3 章插入「小兑现」
- 每 5 章至少一次金色结算或新数据维度
- 每章章末必须有钩子
- TRACK 强制同步更新所有追踪文档
