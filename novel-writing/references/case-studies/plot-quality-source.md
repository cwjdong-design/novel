# 状态更新注入戏剧：实战案例

> 教训来源：2026-08-01 会话。用户指出「AI就是为来写而写」——护栏拦住了垃圾但产不出好故事。

## 问题诊断

章节规划写的是「刘芳报月度财报：首次盈利」。这是状态更新不是故事。直接写 DRAFT 会用搬货、算账、打电话填满2200字，读者跳章。

## 三问诊断法

1. 有人不高兴吗？——所有人都满意=没有冲突
2. 主角做了什么艰难的决定？——没有选择=没有戏剧
3. 下一章的麻烦在这一章种下了吗？——没有钩子=没有追读

## 第33章改造实例

### 注入戏剧的5个回合

1. **开场冲突**：老周带回5人，梁仔（新人）第一句话质疑收虾价——「穗城卖六十你收四十二？」
2. **信息炸弹**：刘芳报账——盈利4.3万，但利润来自差价，和阿坤模式本质一样
3. **当众发难**：梁仔算给所有人听——「42收60卖差18，阿坤当年差17，你比阿坤多赚一块」
4. **主角决策**：林越提价到45。刘芳说利润归零。林越说「利润归零，码头就不会散」
5. **外部钩子**：傍晚来了个陌生人，出48块收虾——冯志强的手伸过来了

### 改造前后对比

| 维度 | 原始规划 | 改造后 |
|------|---------|--------|
| 冲突 | 无 | 3层（渔民vs林越、林越vs自我、外部vs全体） |
| 决策 | 无 | 提价到45，牺牲利润保人心 |
| 钩子 | 无 | 陌生人48块收虾 |
| 人物 | 只用刘芳 | 新人梁仔+刘芳+沈知予 |

## 可复用模式

1. **好消息里藏炸弹**：盈利但结构不可持续；签单但产能不够；建冷库但电费吃利润
2. **受益者和受害者同时在场**：老板赚钱渔民没涨；新人来了挤了老人
3. **用第三方嘴戳破表面**：新人说出大家不敢说的真话——最有效的冲突触发器

## 关键原则

- 质量从 PLOT 决定，不是从 DRAFT
- 容量预审不只数回合数，还要检查是否「有效冲突」而非「状态罗列」
- 4回合=搬货→算账→打电话→等消息，是4个注水段不是4个有效回合
