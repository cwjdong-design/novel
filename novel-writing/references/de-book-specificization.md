# 去书特定化审查流程

> 当技能文件中混入了某本书的硬编码数据（角色名、地名、公式、面板字段），按本流程清理。

## 触发条件

- 技能文件从单书项目升级为多书通用时
- 发现技能文件中包含特定书的角色名 / 地名 / 数字公式 / 面板字段
- 用户要求「移除硬编码」「改为通用占位符」「从书配置读取」

## 需要清理的数据类型

| 类型 | 示例（硬编码） | 替换方式 |
|------|---------------|---------|
| 角色名 | 林越、沈知予、阿坤、刘芳 | `<主角>`、`<配角>` 或「从书配置人物库读取」 |
| 地名白名单 | 穗城/海安/海康/白沙水产市场 | `02-设定文档/书配置.md` 的地名白名单字段 |
| 结算公式 | 287,341 × 系数 × 0.10 | 「结算基数 × 系数 × 结算比例，具体值见书配置」 |
| 面板字段名 | 安居乐业人口/幸福系数/昨日结算 | 「面板字段从书配置读取」+ 通用占位符 |
| 方言指定 | 粤语3-5处 | 「方言/口语点缀3-5处（具体见书配置）」 |
| 作者地域 | 广东湛江人 | 「具体风格参考书配置」 |
| 收入对比示例 | 渔民 300 vs 系统 15000 | 「书配置中的对照组 vs 系统收入」 |

## 审查步骤

1. **读取目标技能文件全文**（注意分页，确保完整读取）
2. **搜索硬编码关键词**：角色名、地名、数字公式、面板字段、方言指定
3. **逐处替换**为配置引用或通用占位符
4. **grep 验证**：对修改后的文件搜索所有已知硬编码词，确认零命中
5. **抽查关键段落**：读取修改后的行，确认语义通顺

## 常见陷阱

- **分页遗漏**：大文件（>500行）需要分页读取，修改前确保已读取全文
- **同一关键词多处出现**：grep 先确认所有出现位置，避免遗漏
- **间接引用**：如 `渔民 300 vs 系统 15000` 不是地名但也是书特定数据——审查时要识别所有书特定内容
- **技能文件引用链**：novel-main.md 引用 novel-skeleton/SKILL.md 和 novel-review.md，三者的硬编码可能交叉出现——需要同时审查

```

```

该文件应包含以下字段（由 novel-writing SKILL.md 的「书配置机制」定义）：

## 方言通用化模式

> 方言是去书特定化的高频项。初版技能文件倾向于硬编码单一方言（如粤语），但通用框架需要支持任何方言。

### 书配置方言字段

```
dialect_type: 粤语 | 四川话 | 东北话 | 上海话 | … | 无
dialect_word_list: [{word, meaning, example}, ...]
dialect_characters: [角色名列表]  # 哪些角色可以使用方言
dialect_frequency: 3-5            # 每章方言词使用上限
```

### 技能文件中的正确写法

- **词表**：不内联硬编码词表，只标注「从书配置 `dialect_word_list` 读取」
- **示例词表**：可保留少量词作为格式演示，但必须标注「⚠️ 以下为粤语示例，实际使用时从书配置读取」
- **角色限制**：不写「广东/湛江背景角色」，写「书配置 `dialect_characters` 中的角色」
- **频率限制**：不写死「3-5处」，写「书配置定义的上限（默认 3-5 处）」
- **自检清单**：检查项引用配置字段名而非具体数字

### 涉及文件清单

方言通用化需要在以下文件中同步修改：
- `novel-draft.md` §3.5（方言注入框架）+ §八（自检清单）
- `novel-polish.md` §五 类型3（方言注入）+ §七（复查清单）
- `novel-review.md` 方言用量检查项
- `novel-skeleton/SKILL.md` 骨架方言铁律

## 脚本参数化模式

> 第二轮改造的核心：让 Python/Shell 脚本从书配置.md 读取规则，而不是硬编码。

### review_scan.py 的 `--book` 参数模式

所有需要书特定规则的脚本，统一使用 `--book <书名>` 参数：
```python
parser.add_argument('--book', '-b', help='书名（自动定位书配置.md）')
parser.add_argument('--config', '-c', help='书配置.md 的完整路径')
```

查找顺序：`--config` 指定路径 > `~/novels/books/<book_name>/02-设定文档/书配置.md` > 默认值回退。

### 书配置.md 解析正则

书配置.md 中的地名白名单在 `##` 标题后的说明文字和 ``` 代码块中。解析时需要跳过说明行：
```python
# 正确的正则（跳过标题和说明，匹配代码块内容）
whitelist_match = re.search(
    r'## 地名白名单\s*\n.*?```\n(.*?)```', content, re.DOTALL
)
# ❌ 错误：r'## 地名白名单\s*\n+```\n(.*?)```'
#    上面会失败——因为标题和代码块之间有说明行
```

### 番茄发布脚本的外置化

`publish_chapter.py` 的 BOOK_ID 和章节 ID 从两个来源读取：
1. `书配置.md` 中的 `番茄BOOK_ID:` 行
2. `02-设定文档/番茄章节ID.json`（独立 JSON 文件）

### novel_step.sh 的脚本委托

novel_step.sh 内嵌的 Python 违禁词检查和地名检查应删除硬编码列表，改为调用 review_scan.py：
```bash
python3 "$SCAN_SCRIPT" "$SKEL" --book "$BOOK_NAME" || exit 1
```
