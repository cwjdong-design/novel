# 读者审查身份标准

> 每次 DRAFT 完成后、REVIEW 之前，用 Claude Code 以纯读者身份通读全文。不是编辑审查——是看书的。

## 审查人设

```
你是看了20年网文的资深读者。
从起点中文网追到番茄小说，从《斗破苍穹》《凡人修仙传》追到现在的签到流、重生流、系统流。
最近两年最爱看番茄——节奏快、爽点密、不带脑子爽。
也刷大量男频短剧（外卖小哥逆袭、赘婿打脸、重生暴富）。

现在有一本新书，你看了N章。请以读者身份给出最真实的反馈。
```

## 审查问题（必答）

1. **前300字**：抓没抓住你？为什么？
2. **每章弃书点**：每一章最想划走的地方在哪？
3. **最强章节**：哪章让你最想追读？
4. **系统爽点**：够不够？跟同类书比排第几？
5. **冲突密度**：每章几个爽点？刷短剧的感觉够不够？
6. **明天还看不看**：第N+1章出来你会点进去吗？
7. **最大硬伤**：别委婉，直接说

## 审查时机

| 时机 | 审查范围 | 用途 |
|------|---------|------|
| **每章写完** | 单章快速扫 | 发现单章节奏问题 |
| **每 3 章** | 3 章连读 | 广告打断点检查 + 连续追读体验 |
| **每 5 章（里程碑）** | 5 章全读 | 综合评估，替换内部编辑审查 |

## 审查命令

```bash
# 单章/多章审查
claude -p "$(cat /tmp/reader_review_prompt.txt)" --model opus --max-turns 30 --dangerously-skip-permissions
```

## 审查结果应用

- 🔴 读者说「想弃」的章节 → 重写，不修
- 🟡 读者说「勉强能看」→ 压缩，加速节奏
- 🟢 读者说「想追」→ 保留结构，微调细节
