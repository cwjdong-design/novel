# opus 生成铁律

> ⚠️ **此文件是特定书籍的生成约束参考，不是通用技能文件。**
> 
> 每本书应在 `02-设定文档/书配置.md` 中定义自己的生成约束。
> 以下内容仅作为书配置的**模板示例**，展示需要约束哪些维度。
> 
> 骨架模式下，约束固化在骨架中，此文件不注入 DRAFT prompt。

## 书配置需要定义的约束维度

每本书的书配置应包含以下区块，供 review_scan、骨架生成、DRAFT 派发时引用：

### 1. 地名白名单

列出书中允许出现的全部架空地名。未在白名单中的地名一律禁止。

```markdown
## 地名白名单
允许：<城市A>、<城市B>、<地点C>...
<城市A>区名：<城市A>东区、<城市A>南区...
禁止：任何真实中国地名（如北京/上海/广州/深圳等）
```

### 2. 人物存活状态

列出当前已出场人物的存活状态，防止 opus 在对话中声称已死角色"还活着"或活人"已死"。

```markdown
## 人物存活状态
- <主角>：活着，<身份>
- <配角A>：活着，<身份>
- <配角B>：活着，<身份>
- <反派>：活着/已退场
```

### 3. 系统面板规范（系统流小说适用）

定义系统面板的固定格式和字段。如果是非系统流小说，此区块省略。

```markdown
## 系统面板
- 面板格式：【字段名：数值】，固定N行
- 固定字段：<字段1>、<字段2>、<字段3>
- 可选附加（≤2行）：<字段4>、<字段5>
- 结算公式：<基数> × <系数> × <比例>（具体值在书配置中定义）
- 结算时间：每日凌晨 00:00
- 禁止措辞：检测到/建议/任务/预警/解锁/阶段/宿主/预估等主动措辞
- 核心原则：系统只被动报数，不主动说话
```

### 4. 关键数字

记录关键设定数字，供骨架生成时校验。

```markdown
## 关键数字
- <设定项1>：<数值>
- <设定项2>：<数值>
- 结算基数：<数值>
- 当前系数：<数值>
```

### 5. 爽点配置（可选）

如果使用爽点注入方法论，定义本书的爽点参数。

```markdown
## 爽点配置
- 普通人日收入参考：<数值>
- 系统日结参考：<数值>
- 对比线人物：<角色>日收入 <数值>
```

---

> **注意**：以上所有数值和设定应该跟随剧情推进而更新。
> 每次 TRACK 步骤后，检查书配置中的数字是否需要同步。
