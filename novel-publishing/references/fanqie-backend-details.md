# 番茄小说后台技术细节

> 2026-07-25 登录联调记录

## 页面结构（已确认）

### 首页
- URL: `https://fanqienovel.com/`
- 头部导航: 首页 / 书库 / 书架 / 原创榜 / **作家专区** / 版权专区
- 点击「作家专区」→ 进入作家专区（未登录状态）

### 作家专区（未登录）
- 显示「请登录」+「欢迎成为番茄作家」
- 「立即登录」按钮 → 弹出登录弹窗

### 登录弹窗
- 两个标签：**验证码登录**（默认）/ **扫码登录**
- 验证码登录：手机号 + 验证码 + 同意协议 → 发送验证码触发滑块 captcha
- 扫码登录：显示二维码 → 用抖音/番茄小说 APP 扫码
- 额外选项：「密码登录」按钮

### 登录后（待首次进入验证）
- 预期：作品列表 → 作品管理 → 章节管理 → 编辑器

## 浏览器自动化发现

### 已验证可用
- `browser_navigate` + `browser_snapshot` + `browser_click` + `browser_type`：页面交互正常
- 扫码登录 + 截图分享：可行

### 已验证障碍
- 验证码登录触发滑块 captcha（iframe 内），无法自动处理
- `computer_use` 在 Chrome 上不暴露网页 AX 树（只有菜单元素）
- `browser_vision` 在当前模型报错但**截图已保存**

### 截图路径格式
```
/Users/<user>/.hermes/cache/screenshots/browser_screenshot_<uuid>.png
```

## 已知问题

1. **⚠️ Session 持久化问题（2026-07-25 发现）**：扫码成功后用户手机端确认登录，但浏览器弹窗跳转到 `about:blank`，登录 cookie/token 未传递到主浏览器会话。导致回到首页后仍显示「登录」状态。需要解决：可能需要在弹窗关闭后通过 `browser_navigate` 回到首页触发 cookie 读取，或使用非弹窗的登录路径。
2. 二维码有时效性（约 2-3 分钟），过期需重新生成
3. 登录后首次进入后台的页面结构尚未校准
4. 定时发布的修改流程（取消定时 → 改草稿 → 重新定时）待验证
5. macOS Chrome 的 `osascript` 读取页面状态会超时（不可靠）
