# 合规与一致性审查（可执行版）

## 输入
- 本章初稿（来自 novel-draft）
- 人物卡（来自 `02-设定文档/人物库/`，含对话风格字段）
- 伏笔追踪表（来自 `02-设定文档/伏笔追踪表.md`）
- 世界观设定（来自 `02-设定文档/世界观.md`）
- 故事线状态（来自 `02-设定文档/故事线状态.md`）
- 前5章正文（用于交叉验证）

> ⚠️ **第 1 章特殊处理**：当审查第 1 章时，无前文章节可用于交叉验证。此时跳过以下检查：前文事件交叉验证（§2.3）、时间线交叉验证中的「日期倒退检查」和「跨章时间跳转检查」。仅做独立审查（OOC、违禁词、基本质量）。在审查报告中标注「第 1 章 — 无前文可比对」。

## 一、OOC检测算法（人物对话语气 vs 人物卡性格匹配）

### 1.1 人物卡对话风格提取
从人物卡 `## 对话风格` 字段提取特征向量：
| 维度 | 取值 | 权重 |
|------|------|------|
| 正式度 | 粗俗(-2) / 随意(-1) / 中性(0) / 正式(+1) / 文雅(+2) | ×1.0 |
| 攻击性 | 温和(-2) ~ 激进(+2) | ×1.0 |
| 话量 | 寡言(-2) / 简练(-1) / 正常(0) / 话多(+1) / 啰嗦(+2) | ×0.8 |
| 情绪化 | 理性(-2) ~ 激动(+2) | ×0.5 |
| 口头禅 | 存在(0.3) / 缺失(0) | ×1.5 |
| 习惯用词 | 匹配(0.3) / 不匹配(-0.5) | ×1.2 |

### 1.2 本章对话特征提取
对本章每个有台词的角色，逐句对话做同样的特征提取。

### 1.3 匹配算法
对每个角色计算 OOC 得分：

```
OOC_score = Σ(weightᵢ × |chapter_featureᵢ - card_featureᵢ| / 4)
          + 口头禅惩罚(口头禅出现次数 < 人物卡设定次数的一半 → +0.3)
          + 用语风格惩罚(逐句用AI判断是否符合人物卡的「对话风格」示例，不匹配比例 > 30% → +0.5)
```

### 1.4 判断阈值
| OOC_score | 级别 | 处理 |
|-----------|------|------|
| 0 — 0.3 | ✅ 正常 | 不报 |
| 0.3 — 0.6 | ⚠️ 轻度OOC | 二级问题，标注「建议检查」，不阻塞 |
| 0.6 — 1.0 | 🔴 中度OOC | 一级问题，标记「建议修改」，阻塞通过 |
| > 1.0 | 🚨 严重OOC | 一级问题，必须修改 |

### 1.5 行为逻辑一致性检查
额外检查以下场景（任一命中即标记 OOC）：
- 冷酷型角色突然流泪（除非有前文情绪铺垫）
- 弱角色正面硬刚强敌且无合理策略（除非人物卡标注「冲动型」）
- 聪明型角色犯低级错误且无前文伏笔
- 恋爱线角色突然对第三者产生强烈好感（情感变化必须跨 ≥3 章铺垫）

## 一点五、人物一致性检查（新增）

### 1.5.1 核心规则

> **杜绝代理擅自创造角色。** 正文中出现的每一个有名字的角色，必须在人物库中有对应注册。

**角色分级体系**：

| 角色级别 | 定义 | 注册要求 |
|---------|------|---------|
| **核心角色** | 有完整剧情线、≥5句台词、影响主线 | 必须有完整人物卡（≥12字段） |
| **次要角色** | 有一定剧情参与度、3-4句台词 | 必须有完整人物卡或简易卡 |
| **路人级角色** | 有名有姓但仅出场1-2句台词 / 1-2段描写 | 必须满足以下之一：<br>① 在人物总表中注册（一行即可）<br>② 拥有**简易卡**（≥6个字段） |

**简易卡概念**：路人级角色不需要完整人物卡，可用简易卡代替。简易卡只需填写以下 6 个字段：

| 字段 | 说明 |
|------|------|
| 姓名 | 角色名字 |
| 性别 | 男/女/其他 |
| 年龄 | 大致年龄段（如「三十出头」「少年」） |
| 身份 | 在故事中的身份/职业（如「茶馆老板」「路人修士」） |
| 出场场景 | 在哪个场景/哪章出现（如「第3章 茶馆偶遇」） |
| 对话风格 | 一句话概括说话方式（如「市井腔、话多」「沉默寡言」） |

> 📋 简易卡模板见 `templates/人物简易卡模板.md`，创作流程见 `novel-character` 技能 §七。

### 1.5.2 检测流程

```
输入: 本章正文 + 02-设定文档/人物库/ 下所有人物卡文件（含简易卡）+ 人物总表
检查:
  1. 从本章正文中提取所有出现的人名（含对话提及、旁白提及）
  2. 从人物库中提取所有已注册角色名（以文件名、人物卡内「姓名」字段、人物总表中的条目为准）
  3. 逐个比对——出现在正文中但不在人物库中的角色名 → 标记
  4. 对每个角色判定级别（核心/次要/路人），根据级别检查注册状态

去重规则:
  - 仅提取首见人名（同一角色多次出现只记 1 处）
  - 常用称谓不视为「角色名」：路人、老者、小二、店长、士兵、守卫、侍女 等通用称呼
  - 「爸」「妈」「师父」「师兄」等称号——如果仅以称号出现且指代已注册角色（如「师父」指代已注册的「张真人」），不视为未注册；如果称号指代一个独立的有独立台词/行动的角色（如「一个陌生师兄走过来说……」），则需考虑是否需要注册
  - **路人级判定**：同时满足以下条件为路人级角色——
    ① 有名有姓（非通用称谓）
    ② 台词/动作描写 ≤ 2 句
    ③ 不推动主线剧情（仅为场景氛围/功能性出场）

简易卡验证规则:
  - 找到角色在人物库中的文件 → 检查是否为简易卡（字段 ≥ 6 个且 ≤ 8 个为简易卡；字段 > 8 个为完整卡）
  - 对路人级角色：有简易卡 → ✅ 通过；有完整卡 → ✅ 通过（超出要求，允许）
  - 对路人级角色：无任何人物卡，但在人物总表中有一行记录 → ✅ 通过
  - 对路人级角色：既无人物卡也无人物总表记录 → ⚠️ 二级问题「未注册角色(路人级)」
```

### 1.5.3 判断阈值

| 检测结果 | 级别 | 处理 |
|---------|------|------|
| 全部角色均在人物库中注册（含简易卡/人物总表） | ✅ 通过 | 不报 |
| 发现路人级角色（有名有姓但仅1-2句台词/出场），既无人物总表注册又无简易卡 | ⚠️ 二级问题「未注册角色(路人级)」 | 建议：① 在人物总表中补一行记录，或 ② 创建简易卡（6字段），或 ③ 改为通用称谓 |
| 发现 1-2 个未注册角色（非路人级），且该角色仅有 1-2 句路人台词 | ⚠️ 二级问题 | 建议：要么在人物库中补注册，要么改为通用称谓（如用「路人」「店员」代替名字） |
| 发现 ≥ 3 个未注册角色（任何级别） | 🔴 一级问题「未注册角色」 | 阻塞通过。必须停止，回到 novel-character 或 novel-new-book 补充人物卡后再审 |
| 发现 1 个未注册角色（非路人级），但该角色有紧密剧情互动（≥ 5 句台词 / 有独立行动线 / 影响主线） | 🔴 一级问题「未注册角色」 | 阻塞通过。核心角色不能无人物卡 |

### 1.5.4 输出格式

在审查报告「五、故意错别字区分」之后追加：

```markdown
### 六、人物一致性
| 序号 | 角色名 | 首次出现位置 | 角色级别 | 人物库状态 | 剧情参与度 | 处理建议 |
|------|--------|-------------|---------|-----------|-----------|---------|
| 1 | 张三 | 第5段 | 核心 | ❌ 未注册 | 5句台词 | 🔴一级：请在人物库补充「张三」完整人物卡 |
| 2 | 李四 | 第12段 | 路人级 | ❌ 未注册(路人级) | 1句台词 | ⚠️二级：请创建「李四」简易卡或在人物总表注册 |
| 3 | 王五 | 第20段 | 路人级 | ✅ 简易卡 | 2句台词 | — |
```

若无未注册角色：
```markdown
### 六、人物一致性
✅ 所有角色均已注册（含简易卡 X 张、人物总表条目 Y 条）
```

> 💡 角色级别列可选值为：`核心` / `次要` / `路人级`。人物库状态列可选值为：`✅ 完整卡` / `✅ 简易卡` / `✅ 人物总表` / `❌ 未注册` / `❌ 未注册(路人级)`。

> ⚠️ 注：原 OOC 详情从「六」顺延为「七」，原剧情矛盾检测从「七」顺延为「八」。

## 二、剧情矛盾检测算法

### 2.1 时间线交叉验证
```
输入: 本章时间标记 + 前5章时间标记
检查:
  1. 日期是否倒退（即本章时间 ≤ 前一章时间）
  2. 同一场景内的时间推进是否合理（用字数/时间比估算，每1000字≥5分钟）
  3. 跨章时间跳转是否有过渡句（跳过 > 3天 必须说明起因）
  4. 多人视角时时间是否同步（同一时间点不同角色的状态不冲突）

阈值:
  - 日期倒退 → 一级问题，阻塞
  - 同场景时间比 < 1分钟/1000字 → 二级问题
  - 跨章跳 > 3天无过渡 → 二级问题
```

### 2.2 人物关系交叉验证

**关系级别定义**：
| 级别 | 名称 | 说明 |
|------|------|------|
| 1 | 陌生人 | 互不相识，无交集 |
| 2 | 认识 | 知道对方、有过简单接触 |
| 3 | 朋友 | 有一定交情，会互相帮忙 |
| 4 | 亲密 | 挚友、恋人、师徒等深度关系 |
| 5 | 至亲 | 血亲、生死之交、灵魂伴侣 |

```
输入: 本章涉及角色对 + 人物库中的人物关系
检查:
  1. 关系级别是否突变（如「陌生人→夫妻」在同一章内）
  2. 称呼是否与当前关系匹配（关系为「仇人」却称兄道弟）
  3. 权力关系是否被无意颠倒（下属命令上级，无合理事件铺垫）
  4. 死亡角色是否被意外「复活」（除非设定支持且伏笔铺垫）

阈值:
  - 关系级别突变 ≥ 2级 → 一级问题，阻塞
  - 称呼与关系冲突 → 一级问题，阻塞
  - 权力颠倒无铺垫 → 二级问题
  - 死亡角色复活无伏笔 → 一级问题，阻塞
```

### 2.3 前文事件交叉验证
```
输入: 本章事件列表 + 故事线状态（含前5章梗概）+ 伏笔追踪表
检查:
  1. 本章是否引用了前文未发生的事件（幻觉事件）
  2. 本章是否否定了前文已发生的事件（以前写过「他杀了A」，本章说「他从未杀过A」）
  3. 物品/能力是否凭空出现（前文未获得，本章直接使用）
  4. 角色知识是否不合理（角色知道了他不可能知道的信息）
  5. 伏笔回收是否与当初铺垫一致（当初暗示「神秘人」，回收时变成「普通路人」=崩坏）

算法: 
  - 用 story_state 摘要做 N-gram overlap（N=5），如果本章出现与前文无 overlap 的新事件描述 → 标记
  - 用伏笔追踪表的「回收方式」字段比对「内容」字段，语义相似度 < 0.3 → 标记崩坏

阈值:
  - 前文幻觉事件 → 一级问题
  - 前文否定 → 一级问题，阻塞
  - 凭空获得 → 二级问题
  - 知识不合理 → 二级问题
  - 伏笔回收崩坏 → 一级问题
```

| 47 | 进行了 | AI味 | 用具体动作替代——「他一拳砸了过去」代替「进行了攻击」 |
| 48 | 极为/极其 | AI味 | 用具体描写替代——「他气得手都在抖」代替「他极为愤怒」 |
| 49 | 最终 | AI味 | 删除或用具体结果替代 |
| 50 | 一方面……另一方面 | 论文句式 | 分为两段叙述 |
| 51 | 显而易见 | AI味 | 用「显然」「明摆着」 |
| 52 | 综上所述 | AI味 | 不写，或直接写结论 |
| 53 | 从某种意义上说 | AI味 | 删除，直接说 |
| 54 | 毫无疑问 | AI味 | 删除或改为具体铺垫 |

> ℹ️ 「随着……的发展」「在……的过程中」属于句式模式，由 novel-draft §1.2 禁用句式 和 novel-review 的 patterns 正则覆盖。「产生了」「发生」「呈现」属于弱动词问题，由抽象表达规则和 novel-polish 文笔打磨覆盖。 |

## 四、故意错别字反向检查

### 4.1 判断逻辑
网文写作中常有故意写错字的情况，需要区分「故意的」和「真错误」。

### 4.2 故意的（不报）
| 类型 | 示例 | 判断依据 |
|------|------|---------|
| 角色口音/方言 | 「咋地」「啥子」「俺们」 | 匹配人物卡「口头禅」或「出身」字段 |
| 古风用语 | 「本座」「尔等」「便是」 | 匹配世界观设定（古代/仙侠） |
| 网络用语 | 「绝绝子」「栓Q」「YYDS」 | 符合角色年龄/职业设定（现代/年轻角色） |
| 谐音梗 | 「栓Q」「绷不住了」 | 出现在对话中，连续出现 |
| 外号/昵称 | 「狗蛋」「二哈」 | 人物卡/前文已建立 |

### 4.3 真错误要报的
| 类型 | 判断标准 | 阈值 |
|------|---------|------|
| 单一错字 | 拼音输入错误，如「在/再」「的/地/得」混淆，且不在对话中 | 出现1次=二级问题，同错出现 > 3次=一级问题 |
| 标点混用 | 中英文标点混用（如英文逗号+中文句子），非对话中 | 整章 > 5处 → 一级问题 |
| 空格异常 | 中文字间出现半角空格 | 任一出现 → 二级问题 |
| 重复字词 | 「他他他」「的的」等 | 任一出现 → 一级问题 |
| 缺字漏字 | 句子明显不通顺 | 人工标注，统计每章 > 2处 → 二级问题 |
| 人称错乱 | 「他」突然变成「她」，角色性别不一致（非剧情需要） | 任一出现 → 一级问题 |

### 4.4 检测算法
```
对每章正文:
  for 每个句子:
    - 判断是否在对话段内（引号内）
    - 如果在对话中:
        - 匹配人物卡口头禅/方言特征 → 跳过
        - 匹配常见网络用语/谐音梗 → 跳过
        - 「的/地/得」「在/再」混用 → 视为角色口语化表达，交由 OOC 检测（§1）根据角色口语特征判断是否为故意；若对话角色为知识分子/高冷型则标记为 OOC 问题
    - 如果不在对话中（叙述段落）:
        - 「的/地/得」「在/再」混用 → 一律视为真错误，按 §4.3 阈值处理
        - 检查中英文标点混用
        - 检查基本错字
        - 检查重复字词正则: r'([\u4e00-\u9fff])\1{2,}'
  → 输出区分「对话内口语变体（由OOC判定）」和「叙述段真错误」两类
```

## 五、质量评分量化标准

### 5.1 评分维度与权重

| 维度 | 权重 | 满分 | 评分标准 |
|------|------|------|---------|
| 对话自然度 | 20% | 5分 | 见下方 |
| 节奏把控 | 20% | 5分 | 见下方 |
| 钩子吸引力 | 15% | 5分 | 见下方 |
| 信息增量 | 15% | 5分 | 见下方 |
| 文笔流畅度 | 10% | 5分 | 见下方 |
| 番茄平台适配 | 10% | 5分 | 见下方 |
| OOC控制 | 10% | 5分 | 见下方 |

### 5.2 各项评分细则

**对话自然度（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 每角色对话风格明显不同，与人物卡100%一致，无模板感 |
| 4 | 主要角色对话有区分度，次要角色略同质化 |
| 3 | 角色间对话差异不明显，但读起来自然 |
| 2 | 明显存在多角色说一样的话/语气雷同 |
| 1 | 对话像叙述，缺乏口语感，或严重OOC |

**节奏把控（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 前300字切入场景 + 中段推进冲突 + 末段推向高潮 + 钩子，节奏张弛有度 |
| 4 | 节奏框架完整，某一段略拖沓（如前300字超出50字以上） |
| 3 | 有明显拖沓段或过快段，但整体可读 |
| 2 | 连续两段节奏问题（如中段无冲突推进） |
| 1 | 全章平铺直叙，无起伏，或节奏极度混乱 |

**钩子吸引力（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 钩子制造了明确的悬念/反转/新危机，让人立刻想看下一章 |
| 4 | 钩子有悬念但不够强烈，或方式老套但有效 |
| 3 | 钩子存在但吸引力一般（如简单的「突然……」「就在这时……」） |
| 2 | 钩子模糊，不清楚下一章会发生什么 |
| 1 | 无钩子或钩子完全无吸引力（如「他不知道未来会怎样」） |

**信息增量（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 本章推进了至少2条信息线（主线推进 + 新伏笔 + 世界观扩充 + 新角色信息等） |
| 4 | 推进了1条信息线，且信息量充足 |
| 3 | 推进了1条信息线，但信息量不足 |
| 2 | 有少量信息增量，但本章主要功能是过渡 |
| 1 | 纯过渡章，读者读完感受不到任何剧情推进 |

**文笔流畅度（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 无错别字、无标点混乱、句式有变化、段落 ≤ 5行、无禁用词 |
| 4 | ≤2个二级问题 |
| 3 | 3-5个二级问题 或 1个一级问题 |
| 2 | 6-10个二级问题 或 2-3个一级问题 |
| 1 | >10个二级问题 或 >3个一级问题 |

**番茄平台适配（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 字数 2000-3000（目标2500），对话 ≥ 40%，无违禁词，无禁用句式，段落 ≤ 5行 |
| 4 | 字数偏差 ≤ 150字，或对话占比 35%-39% |
| 3 | 字数偏差 150-300字，或对话占比 30%-34%，或 ≤2 个禁用句式 |
| 2 | 字数偏差 > 300字，或对话 < 30%，或 ≥3 个禁用句式 |
| 1 | 字数严重不符，或多名禁用句式/违禁词命中 |

**OOC控制（5分制）**
| 分数 | 标准 |
|------|------|
| 5 | 所有角色 OOC_score ≤ 0.2 |
| 4 | 仅1个角色 OOC_score 0.2-0.3 |
| 3 | 1个角色 OOC_score 0.3-0.5，或 ≥ 2个角色 OOC_score 0.2-0.3 |
| 2 | 1个角色 OOC_score > 0.5，或 ≥ 3个角色 OOC_score 0.3-0.5 |
| 1 | ≥ 2个角色 OOC_score > 0.5 |

### 5.3 综合评分计算
```
综合分 = Σ(维度得分 × 权重)
       = 对话 × 0.20 + 节奏 × 0.20 + 钩子 × 0.15 + 信息增量 × 0.15 
         + 文笔 × 0.10 + 平台适配 × 0.10 + OOC × 0.10
```

### 5.4 综合评级
| 综合分 | 评级 | 含义 |
|--------|------|------|
| 4.5 ~ 5.0 | ⭐⭐⭐⭐⭐ | 可直接发布 |
| 3.5 ~ 4.4 | ⭐⭐⭐⭐ | 建议发布，小修即可 |
| 2.5 ~ 3.4 | ⭐⭐⭐ | 需修改后发布 |
| 1.5 ~ 2.4 | ⭐⭐ | 需大幅修改，建议重写部分段落 |
| 1.0 ~ 1.4 | ⭐ | 建议重写本章 |
