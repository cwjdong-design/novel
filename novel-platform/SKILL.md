# 番茄小说平台运营指南

## 概述

从十年网文爆款作家视角，系统讲解番茄小说平台的推荐机制、数据指标、运营节奏和读者互动策略。所有操作标准以「万订」为目标。

---

## 一、番茄推荐池机制

番茄采用**阶梯式流量放大**模型：平台用小流量验证数据 → 数据达标 → 放大流量 → 再验证 → 再放大。

### 1.1 四个阶段

| 阶段 | 曝光量级 | 核心考核指标 | 达标线（参考） | 关键动作 |
|------|---------|-------------|--------------|---------|
| **新书入库** | 几百次 | 首章点击转化率、前 300 字跳出率 | 转化率 ≥ 15%，跳出率 ≤ 30% | 打磨书名、简介、开头 300 字 |
| **小量验证** | 几千次 | 读完率、跟读率 | 读完率 ≥ 25%，跟读率 ≥ 15% | 保持日更节奏，章节质量稳定 |
| **中量放大** | 几万次 | 追读率、留存率、互动率 | 追读率 ≥ 10%，7 日留存 ≥ 20% | 沟通读者，优化章末钩子 |
| **大量爆发** | 几十万次 | 收入、全渠道数据 | 稳定在万订水平 | 多书联动，品牌化运营 |

### 1.2 触发条件

- **新书入库 → 小量验证**：首章字数 ≥ 2000 字，发布后自动进入
- **小量验证 → 中量放大**：连续 3 天数据达标
- **中量放大 → 大量爆发**：连续 7 天数据达标，无断更记录
- **任何阶段降级**：连续 2 天数据不达标 → 降回上一阶段

### 1.3 注意事项

- 推荐池切换有 24-48 小时延迟，不是即时反馈
- 断更是推荐池最大的敌人——一次断更可能直接退回新书库
- 数据达标≠保证晋级，平台同期竞争书的数量也影响分配

## 二、核心数据指标

### 2.1 五大核心指标

| 指标 | 定义 | 重要性 | 优化手段 |
|------|------|--------|---------|
| **读完率** | 从第一章读到最新章的比例 | ⭐⭐⭐⭐⭐ | 节奏控制、钩子密度、去水 |
| **跟读率** | 发布后 24 小时内阅读新章的比例 | ⭐⭐⭐⭐⭐ | 更新频率稳定、章末钩子强 |
| **追读率** | 连续阅读 3 章以上的比例 | ⭐⭐⭐⭐ | 每 3 章一个小高潮 |
| **首章点击转化率** | 看到书名→点进第一章的比例 | ⭐⭐⭐⭐ | 书名、封面、简介 |
| **前 300 字跳出率** | 看了前 300 字就退出的比例 | ⭐⭐⭐⭐⭐ | 开头 300 字必须抓人 |

### 2.2 数据仪表盘（写作时盯盘重点）

```
每日必看：
├── 跟读率（今天的章有多少人看了）→ 反映今天的质量
├── 读完率（累计有多少人还在追）   → 反映整体质量
└── 新增收藏（今天加了几个收藏）   → 反映增长趋势

每周必看：
├── 追读率       → 连续阅读的粘性
├── 7 日留存     → 一周后还有多少人
└── 评论量/互动量 → 读者活跃度
```

### 2.3 数据诊断速查

| 问题 | 症状 | 对策 |
|------|------|------|
| 开头不行 | 首章转化率 < 12% | 重写前 300 字，改书名和简介 |
| 中间水了 | 读完率持续下降 | 回看最近 5 章，删废话，加冲突 |
| 追读掉 | 追读率 < 8% | 每章结尾加钩子，保证每章都有推进 |
| 读者跑了 | 7 日留存 < 15% | 主线节奏加快，减少支线和过渡章 |

## 三、日更节奏

### 3.1 标准节奏

| 时段 | 动作 | 原因 |
|------|------|------|
| **上午 10:00-12:00** | 发布第一更 | 上班族午休前的碎片时间，高峰流量前抢占推荐位 |
| **晚上 20:00-22:00** | 发布第二更 | 全天最大的阅读高峰，番茄用户活跃度最高 |

### 3.2 每章规格

- **字数**：2500 字/章（番茄标准，目标2500字）
- **波动范围**：2000-3000 字，不要低于 1800 或高于 3200
- **两天一更**：最低底线，低于此频率直接影响推荐池地位

### 3.3 不同阶段的更新策略

| 阶段 | 日更量 | 策略 |
|------|--------|------|
| 新书期（前 10 章） | 1 更/天 | 保持稳定，重在质量，建立读者信任 |
| 冲量期（第 10-50 章） | 2 更/天 | 配合推荐池放量，快速积累章节数 |
| 稳定期（50 章后） | 1-2 更/天 | 以不牺牲质量为前提，可降到 1 更保质量 |
| 特殊时期（节假日/爆更） | 3-5 更/天 | 提前存稿 ≥ 10 章，爆发前通知读者 |

## 四、存稿策略

### 4.1 缓冲标准

```
最低缓冲：5 章（断更的最后防线）
安全缓冲：10 章（可以应对突发情况）
健康缓冲：20 章以上（可以策划爆更活动）
```

### 4.2 存稿管理

```markdown
~/novels/books/<书名>/01-正文存稿/
├── ch_0051.md   ← 今日发第 51 章
├── ch_0052.md   ← 明天发第 52 章
├── ch_0053.md   ← 存稿
├── ch_0054.md   ← 存稿
├── ch_0055.md   ← 存稿
└── ch_0056.md   ← 正在写第 56 章
```

### 4.3 存稿原则

1. **存稿不囤稿**：存稿是为了应对断更风险，不是无限超前写——超前太多等于浪费
2. **存稿也要审查**：存稿发布前必须再过一遍 novel-review，避免存稿过期（设定已变）
3. **缓冲跌破 3 章——拉警报**：立即暂停其他工作，全力补到 5 章以上
4. **爆更前提前 3 天通知读者**：给读者期待感，提升爆发当天的跟读率

## 五、读者互动

### 5.1 章末「作者的话」写法

番茄允许在每章末尾写一段作者的话，这是跟读者建立关系的黄金位置。

**原则**：
- 每次 50-80 字，不超过 100 字
- 必须带行动号召（投票/评论/追读）
- 不要道歉、不要卖惨、不要解释剧情

### 5.2 三种模板

#### 模板 A：引导评论（互动型）

适用于：有悬念、有争议、有选择点的章节。

```
> 这一章结尾你们猜到了吗？评论区说说——主角接下来会选哪条路？A. 硬刚  B. 先苟着。
> 明天同一时间揭晓。
```

**效果**：评论区活跃 → 互动率高 → 推荐池加分。

#### 模板 B：引导投票（增长型）

适用于：需要数据冲刺的阶段。

```
> 如果你喜欢这种节奏，点个催更。催更破 500 明天加一更！
> 咱们说好的，说到做到。
```

**效果**：催更数据好 → 平台判定为高需求 → 推荐放量。

#### 模板 C：引导追读（留存型）

适用于：章末有大钩子的章节。

```
> 明天这一章，会揭晓那个电话是谁打的。
> 提示：不是你们想的任何一个人。
```

**效果**：制造期待 → 提高明天的跟读率 → 留存率稳定。

### 5.3 不要做的事

- ❌ 「今天状态不好，写得不好请见谅」——读者不会体谅，只会弃书
- ❌ 「这章可能有点水」——你自己都说水，读者为什么看？
- ❌ 「求求你们投票吧」——卖惨降低读者期待，高姿态引导更有效
- ❌ 解释剧情——如果剧情需要解释，说明没写好。重写，别解释。
- ❌ 超过 100 字的作者的话——喧宾夺主，读者是来看小说的。

## 六、广告打断应对策略

### 6.1 番茄广告机制

番茄每 3-4 章插入一次广告。广告是在章节切换时出现的，所以**每 3-4 章的结尾是广告插入点**。

### 6.2 广告打断的核心问题

广告插入 → 读者看完广告 → 可能就不回来了。

**你的任务**：在广告插入点（每 3-4 章的结尾）制造强悬念，让读者看完广告还想着回来。

### 6.3 广告点位设计

按章号判断广告点位（3 章一个周期）：

```
第 3 章结尾 ← 广告点 1：中等钩子
第 6 章结尾 ← 广告点 2：强钩子
第 9 章结尾 ← 广告点 3：最强钩子（三章一个小高潮）
```

### 6.4 广告点钩子强度分级

| 广告点类型 | 钩子强度 | 写法 |
|-----------|---------|------|
| 普通章末 | 轻度悬念 | 正常的章末钩子（参考 novel-draft §5） |
| 广告点章末 | 强悬念 | 必须制造「马上要知道结果」的紧迫感 |
| 小高潮章末 | 超强悬念 | 关键信息只差临门一脚，戛然而止 |

### 6.5 广告点专用钩子模板

#### 模板 1：信息截断型

在关键时刻切断信息流。

```
> 他翻开最后的文件，上面只写了三个字——
```

（读者看完广告回来就是为了知道这三个字是什么）

#### 模板 2：视角切换型

在高潮点切换到另一个场景，制造双重悬念。

```
> 楼下传来玻璃碎裂的声音。
> 
> 会议室里，所有人同时安静了。
```

（用环境+群体反应代替直接描写，给读者脑补空间）

#### 模板 3：倒计时型

给读者一个紧迫的时间预期。

```
> 系统提示：【自毁程序启动。倒计时：00:59:58】
> 
> 「所有人——」
> 
> 话没说完，天花板塌了。
```

（读者会想「塌了之后呢？」→ 看完广告回来）

### 6.6 广告点写作原则

1. **不要在广告点前写「一小段安静」的段落**——广告点前节奏必须加速
2. **广告点前 300 字是黄金位置**——必须设置悬念
3. **广告点后的第一章开头要立刻接上悬念**——不要换场景，不要「第二天」
4. **不要每 3 章都用同一类型的钩子**——穿插使用，避免套路化

## 七、运营节奏总览

### 7.1 新手 30 天起号计划

| 阶段 | 天数 | 日更 | 核心任务 |
|------|------|------|---------|
| **冷启动** | 第 1-10 天 | 1 更/天 | 打磨开头 5 章，保证读完率 |
| **蓄力期** | 第 11-20 天 | 2 更/天 | 积累 10 章存稿缓冲 |
| **冲刺期** | 第 21-25 天 | 2 更/天 | 全力冲跟读率，追求推荐池晋级 |
| **爆发期** | 第 26-30 天 | 2 更/天 | 配合推荐放量，爆更 3-5 章 |

### 7.2 每日运营清单

```
上午：
□ 发布第一更（如有）
□ 查看昨日数据（跟读率、读完率、新增收藏）
□ 回复精彩评论（挑 3-5 条有质量的回复）

下午：
□ 写第二更 / 补充存稿
□ 检查存稿缓冲是否 ≥ 5 章

晚上：
□ 发布第二更
□ 写章末作者的话
□ 浏览番茄热榜（了解市场风向，不抄袭）
```

## 注意事项

- **数据是反馈，不是目标**：追数据追到失眠反而影响写作品质。写得好才有数据，不是反过来。
- **断更是最大的敌人**：宁可缩短字数也不断更。2000 字保底 > 0 字。
- **不要跟风**：看到哪种类型火就去写那种——等你写出来风向已经变了。写自己擅长的。
- **广告点是机会不是敌人**：强钩子让广告反而成为增强读者粘性的工具。
- **平台规则随时变**：以番茄官方最新公告为准，本技能给出的是历史经验总结。
