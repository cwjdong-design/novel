# 爽点注入方法论

> ⚠️ **特定书籍复盘文档**：以下内容来源于特定书籍的实战经验，其中的章节号、人物名、地名、数字均为该书的设定。方法论部分可通用参考，但具体数据不具有普适性。

> 在「弃书率 100%」诊断后总结的番茄网文核心修复框架。

## 诊断信号

读者反馈「不爽」「憋屈」「无感」→ 检查 5 项：

### 1. 钱是数字还是武器？
- ❌ 系统结算 → 看一眼 → 心里算账 → 继续干活
- ✅ 系统结算 → 立刻花出去 → 配角震惊 → 问题解决

### 2. 有没有「他们不懂」的神秘感？
- ❌ MC 解释「我在穗城做过六年水产」
- ✅ MC 展示异常能力 → 配角愣住 → MC 不解释

### 3. 有没有打脸节奏？（每章至少一次）
- 被质疑/被看低 → 展示实力 → 对方闭嘴
- 对象可变：渔民、阿坤手下、海昌来人、甚至家人

### 4. 有没有收入对比？
- 锚点：渔民日入 300、女工月薪 1800、系统日结 15000
- 不强制每章，但不超过两章不出现

### 5. 系统是金手指还是计算器？
- ❌ 系统只提供数字，MC 靠自己奋斗
- ✅ 系统是 MC 的秘密武器，配角无法理解来源

## 8 章回修实录

| 章 | 问题 | 注入方案 |
|-----|------|---------|
| 1 | 系统数字无震撼 | +渔民收入对比 → 「这是武器」 |
| 2 | 只在心里算账 | +母亲起疑 → 不解释 |
| 3 | 专业知识未展示 | +摸铭牌 → 老周愣住 |
| 4 | 算账无人见证 | +刘芳观察 → 「像在算数学题」 |
| 5 | 结算未落地 | +立刻决定取钱交电费 |
| 6 | 打脸后无真金白银 | +当阿坤面甩现金 |
| 7 | 钱来源无人问 | +阿辉问「哪来的？」→ 不解释 |
| 8 | 80万未对比系统 | +内心算账 → 冷笑 |

## 每章注入检查清单

```
[ ] 系统钱花出去了？花给谁？对方反应？
[ ] 有人不理解 MC 的能力/资源？MC 解释了吗？
[ ] 有打脸？（质疑→实力→闭嘴）
[ ] 有收入对比？
[ ] 系统面板出现时 MC 是「行动」不是「算账」？
```

任一项「否」→ 该章需注入爽点。
