# opus 生成反模式（2026-07-25 实战记录）

> ⚠️ **特定书籍复盘文档**：以下内容来源于特定书籍的实战经验，其中的章节号、人物名、地名、数字均为该书的设定。方法论部分可通用参考，但具体数据不具有普适性。

> 即使铁律完整注入，opus 仍会系统性地违反以下约束。每次 DRAFT 回来必须逐条扫描。

## 1. 面板游戏化
opus 会绕过「系统只报数不说话」的约束，通过「美化面板格式 + 增加非说话字段」来间接注入分析/判断。

### 违规示例
```
╔═══════════════════════╗
║  连续运营天数：5天   ║
║  动态上浮：+25%       ║
║  循环状态：资金→收购→渠道 ║
║  回报周期：预估14天   ║
║  外部合作意向：有     ║
╚═══════════════════════╝
```

### 为什么违规
- 表格边框（╔══╗）= 游戏化视觉
- 「动态上浮」「循环状态」「回报周期」= 系统在分析，不是报数
- 「外部合作意向：有」= 系统在判断
- 「预估」= 系统在预测

### 正确格式
```
【安居乐业人口：287,341】
【幸福系数：0.55】
【昨日结算：¥15,803】
```
仅三行。偶尔可加被动统计如「连续运营天数：3」，但不得带任何分析性字段。

## 2. 数字篡改
opus 会擅自改变已锁定的关键数字。

| 锁定的数字 | opus 篡改为 |
|-----------|------------|
| 人口 287,341 | 91.2 万 |
| 林越年龄 22 岁 | 不到十八岁 |
| 日结算 ¥14,940 | ¥32,400 / ¥40,500 |
| 累计结算 ¥63,590 | ¥126,390 |

## 3. 系统功能发明
opus 会在不违反「不发布任务」的表面规则下，发明新功能：
- 「外部合作意向」= 把剧情事件变成系统字段
- 「主动投放资金」= 把 MC 的花钱行为变成系统术语
- 「本轮资本效率：投入已覆盖」= 系统在评估

## 扫描策略
每次 DRAFT/POLISH 回来后，在存盘前搜索：
```
╔         → 游戏化边框
动态上浮   → 分析字段
循环状态   → 分析字段
回报周期   → 预测字段
预估       → 系统预测

不到十八岁 → 年龄篡改
```
命中任何一条 → 不存盘，发回重写。
