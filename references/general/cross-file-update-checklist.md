# 跨文件标准更新清单

当修改小说技能库中的**全局性标准**（如字数、审查维度、格式规则）时，以下文件必须逐一遍历：

## 必须检查的文件列表

### 核心技能文件
- `novel-writing/SKILL.md` — 入口技能，7步循环、铁律、质量保障
- `novel-new-book.md` — 骨架检查、模板生成
- `novel-main.md` — 状态机、字数要求、前置检查
- `novel-draft.md` — 章节结构、黄金三章布局、自检清单
- `novel-review.md` — 审查算法、评分表、输出格式
- `novel-prep.md` — 上下文摘要、伏笔分析

### 配套文件
- `novel-platform/SKILL.md` — 平台运营（每章规格、更新策略）
- `README.md` — 技能对照表
- `templates/章节模板.md` — 章节模板
- `knowledge/番茄风格指南.md` — 写作铁律

## 本次更新的教训

### 1. 字数标准变更（1800-2200 → 2000-3000）
触及文件：11 个（上述全部 + novel-platform, novel-prep 中的字数检查点）

### 2. 新增审查维度（人物一致性）
- 插入位置在 OOC 检测之后、剧情矛盾检测之前
- **关键教训**：插入新章节会打乱输出格式编号，必须同时更新 §1.5.4 的输出格式示例 和 末尾的审查报告模板
- 兄弟代理（sibling agents）可能在编辑同一文件，re-read 后再写

### 3. 骨架检查（阶段 3.5）
- novel-new-book.md 新增拦截逻辑，需在 novel-writing.md 铁律中同步描述
- 检查项从旧版「5项」改为实际「4项」后，入口技能描述必须同步

### 4. 规划拦截（novel-main 前置检查#5）
- 原逻辑允许第1章从主线大纲提取替代，改为硬拦截后影响所有章节流程
