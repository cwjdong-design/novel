# 人物深度塑造

## 概述

从十年网文爆款作家视角，系统讲解如何塑造让读者记住的人物。人物不是「性格特征列表」的堆砌——真正的人物是靠弧光、欲望、缺陷和对话活起来的。

---

## 一、三幕弧光模板

### 1.1 弧光定义

人物弧光 = 人物从故事开始到结束的内在变化轨迹。

**核心公式**：
```
起点信念 → 触发事件(信念被挑战) → 信念动摇 → 低谷 → 重建(新信念)
```

### 1.2 三幕弧光拆解

| 幕 | 阶段 | 人物状态 | 写作要点 |
|-----|------|---------|---------|
| **第一幕** | 起点信念 | 人物有一套深信不疑的世界观 | 用具体场景展示信念，不要旁白解说 |
| **第一幕末** | 触发事件 | 发生一件足够大的事，撼动了这个信念 | 强度必须大到人物无法忽视 |
| **第二幕** | 信念动摇 | 旧信念失效，新信念还没建立，人物迷失 | 这是人物最像人的阶段——纠结、自我怀疑 |
| **第二幕末** | 低谷 | 人物跌到谷底，失去了所有依赖 | 网文里可以是实力被废、众叛亲离、计划全盘失败 |
| **第三幕** | 重建 | 人物在谷底找到真正重要的东西，建立新信念 | 不是回到原来的信念，是「升级版」——保留了旧信念的一部分，但更有智慧 |

### 1.3 弧光模板速查

```
第一幕：
  ■ 人物相信什么？（一句话）
  ■ 这个信念从哪来的？（童年/经历/创伤）
  ■ 什么事会挑战它？（触发事件）

第二幕：
  ■ 旧信念失效后，人物怎么应对？（逃避/愤怒/假装没事）
  ■ 谁在帮他？谁在打击他？（配角功能）
  ■ 低谷是什么状态？（具体场景）

第三幕：
  ■ 新信念是什么？（比旧信念更高级）
  ■ 怎么验证新信念？（用一场关键行动来证明）
  ■ 代价是什么？（改变必须有代价）
```

### 1.4 范例：从弱到强的弧光

```
旧信念：「我太弱了，我不配。」
触发事件：被逐出师门，师父说「你没有天赋」。
动摇阶段：到处碰壁，反而发现自己不靠天赋也能行。
低谷：被曾经的同门打残，躺在山洞里三天。
新信念：「弱不是原罪，认命才是。」
验证行动：用自己摸索的土办法打败天赋型对手。
代价：永远无法修行正规功法，但走出了一条野路子。
```

## 二、Want vs Need 模型

### 2.1 定义

| 概念 | 定义 | 人物意识 | 例子 |
|------|------|---------|------|
| **Want（外在目标）** | 人物自己认为他想要的东西 | 清醒的、说得出 | 「我要成为天下第一高手」 |
| **Need（内在需求）** | 人物真正需要的东西 | 无意识的、不自知的 | 他真正需要的是「被认可」，不是「比所有人都强」 |

### 2.2 为什么这个模型有用

- **Want 驱动剧情**：人物追 Want，产生行动，推动故事
- **Need 驱动弧光**：人物在追 Want 的过程中，渐渐发现自己真正想要的是 Need
- **Want vs Need 的冲突 = 戏剧张力**：人物越追 Want，离 Need 越远 → 矛盾越来越尖锐 → 弧光越来越强

### 2.3 模型应用三步法

**Step 1：定义 Want 和 Need**

```
Want（人物自己说的）：
  → 「我要报仇。」
  
Need（人物潜意识真正需要的）：
  → 他需要的是「放下仇恨，为自己活一次」。
```

**Step 2：制造冲突——追 Want 让 Need 越来越远**

```
追 Want 的过程：
  → 为复仇不择手段，伤害了无辜的人（包括他在乎的人）
  → 越来越强大，却越来越孤独
  → 仇人找到了，但复仇后并没有满足感
```

**Step 3：转折——在低谷发现 Need**

```
关键转折场景：
  → 复仇成功的那一刻，身边所有人都走了
  → 他坐在仇人的尸体旁，意识到：赢了，又怎样呢？
  → 开始第一次思考「我除了复仇还能做什么」
```

### 2.4 Want/Need 速查表

| 网文常见 Want | 隐藏的 Need |
|-------------|-----------|
| 我要变强 | 我需要安全感 / 我需要被尊重 |
| 我要报仇 | 我需要放下 / 我需要为自己活 |
| 我要得到她 | 我需要的不是占有，是真实的连接 |
| 我要证明别人错了 | 我需要接纳自己本来的样子 |
| 我要当天下第一 | 我需要找到值得保护的人 |
| 我要活下去 | 我需要找到活下去的意义 |

## 三、致命缺陷（Fatal Flaw）

### 3.1 定义

**致命缺陷** = 人物性格中一个会持续造成问题的特质。不是小毛病，是贯穿全文、推动剧情、制造危机的核心弱点。

### 3.2 三种常见致命缺陷

| 类型 | 表现 | 网文适用场景 |
|------|------|-------------|
| **傲慢** | 看不起对手，低估危险 | 爽文经典：打脸之前必先装逼，装逼就是傲慢的表现 |
| **不信任** | 不相信任何人，所有事都要自己扛 | 制造误解和悲剧的最佳工具 |
| **逃避** | 遇到真正重要的事就躲 | 人物成长弧光最清晰的路线 |

### 3.3 致命缺陷的设计标准

```
✅ 好缺陷：
  - 和人物的强项是同一件事的两面（越强越暴露缺陷）
  - 直接导致剧情中的主要危机（不是可有可无）
  - 人物自己意识不到（至少前期意识不到）
  - 在彻底改变之前，缺陷会反复出现

❌ 坏缺陷：
  - 无关痛痒的小毛病（怕蜘蛛、喜欢喝酒——如果喝酒不推动剧情就没用）
  - 说改就改（第二十章突然变得谦逊了）
  - 旁白告诉读者的（「他是一个傲慢的人」→ 要用行动展示）
```

### 3.4 致命缺陷推动剧情的三步循环

```
1. 缺陷导致错误选择
   → 因为傲慢，拒绝了一个重要盟友的帮助

2. 错误选择导致危机
   → 盟友转投对手，主角陷入孤立无援的困境

3. 危机逼迫人物面对缺陷
   → 被逼到绝路，被迫承认「我一个人真的不行」
```

**关键**：第三阶段不能一蹴而就。人物应该反复犯同类错误→反复付出代价→量变到质变。

### 3.5 缺陷与金手指的关系

网文主角通常有金手指。**致命缺陷 = 金手指的反面**：

| 金手指 | 致命缺陷 |
|--------|---------|
| 无限成长系统 | 过度依赖系统，丧失了自主判断力 |
| 重生记忆 | 过度依赖「已知」，当历史改变时完全不知所措 |
| 无敌力量 | 傲慢，轻敌，总觉得自己不需要帮助 |
| 鉴宝/透视 | 只看表面价值，忽略了人心的价值 |

## 四、配角功能分类

### 4.1 四种功能（非角色类型）

每个配角可以承担多个功能。功能不是固定的——一个角色可以在不同阶段切换功能。

### 4.2 功能速查

| 功能 | 定义 | 对主角的作用 | 网文案例 |
|------|------|-------------|---------|
| **催化剂** | 推动主角行动的人 | 逼主角做出选择 | 师父把主角逐出师门 → 主角被迫独立 |
| **镜像** | 和主角相似但做了不同选择的人 | 让主角看到「如果我选另一条路会怎样」 | 同期师兄弟，一个走正道一个走邪道 |
| **阻碍** | 主动或被动阻碍主角的人 | 制造冲突和危机 | 反派、竞争对手、不理解主角的家人 |
| **揭示** | 通过对话/行动透露主角内心的人 | 让读者了解主角的真实想法 | 知己、吐槽役队友、逼主角说实话的人 |

### 4.3 功能使用指南

```
催化剂写得好 = 剧情推进自然
  → 不是主角「突然想通了」，是催化剂逼他必须选

镜像写得好 = 人物有深度
  → 主角的选择不是理所当然的，镜像展示了另一条路的诱惑

阻碍写得好 = 冲突有张力
  → 最好的阻碍不是单纯的反派，是「有道理的反派」

揭示写得好 = 读者共情
  → 主角不说的心里话，让揭示角色替他说
```

### 4.4 反例：功能单一的角色

❌ 一个角色只有一个功能：
```
老王 = 只能当催化剂。每次出场就是告诉主角一个消息，说完就退场。
```

✅ 一个角色可以承担多个功能：
```
老王 = 催化剂（告诉主角消息）+ 镜像（老王年轻时和主角一样冲动，但选错了路）+ 揭示（老王是唯一能让主角说真话的人）
```

## 五、对话潜台词（子文本）

### 5.1 三层模型

每一段对话都有三个层面：

```
第一层：角色说了什么（台词）
第二层：角色真正想什么（内心）
第三层：角色实际意图（行动目的）

张力 = 第一层 ≠ 第二层 ≠ 第三层
```

### 5.2 三层冲突示例

#### 示例 1：关心 vs 控制

```
场景：母亲对刚打完架的儿子

第一层（台词）：
「你怎么又打架了！？你看看你这样子！」

第二层（内心）：
她怕他受伤。怕他跟人结仇。怕他走上他爸的老路。

第三层（意图）：
想让他听话，不要再冒险。但她知道说「我担心你」他不会听，所以用愤怒来表达。
```

```
✅ 写作呈现（不解释，让读者自己读出来）：
他妈看了一眼他的脸，什么都没说。
去厨房拿药箱。
药箱放在桌上，力气大得杯子都震了一下。
「我没——」
「闭嘴。」
她把药水拍在桌上，「自己擦。」
转身的时候，他看见她的手在抖。
```

#### 示例 2：试探 vs 警惕

```
场景：两个初次见面的高手

第一层（台词）：
A：「阁下好身手。」
B：「过奖。你也不差。」

第二层（内心）：
A：这人用的招式我看不出来路。是敌是友？
B：他在试探我。不能暴露底细。

第三层（意图）：
A：想逼对方出招，判断身份。
B：用客气话挡住，不接招。
```

```
✅ 写作呈现：
「阁下好身手。」话是笑着说的，但眼睛没笑。
「过奖。你也不差。」
两个人隔了三步远。这个距离——伸手够不到，出刀最顺手。
```

#### 示例 3：告别 vs 挽留

```
场景：女主提出分手，男主回应

第一层（台词）：
「行。你走吧。」

第二层（内心）：
不要走。

第三层（意图）：
他骄傲到宁可失去她，也不想表现出脆弱。他在赌她会回头。
```

```
✅ 写作呈现：
「行。你走吧。」
他说完低头点了根烟。打火机打了三次才着。
她站在门口，等了几秒。
他没抬头。
门关上的声音很小。他把烟掐了，一口没抽。
```

### 5.3 潜台词写作铁律

1. **不解释内心**：角色在想什么，用动作和环境呈现，不用旁白说出来
2. **不让人物说真话**：除非角色设定为「耿直到说啥是啥」——即使是这种人，也有不会说出口的东西
3. **对话的重点是「没说出来的」**：台词的间隙、沉默、动作打断——这些才是真正的信息
4. **三思而后说**：每句台词问自己：这句话背后藏着什么？如果什么都藏不住，考虑让人物闭嘴。
5. **同一句话，不同人说意思不同**：「没事」——强者说的是不屑，弱者说的是逞强，骗子说的是心虚。

## 六、人物创作清单

### 6.1 创建主角时必回答的 10 个问题

```
1. 他相信什么？（第一幕的起点信念）
2. 这个信念有缺陷吗？（致命缺陷的根源）
3. 他的 Want 是什么？（他自己认为的目标）
4. 他的 Need 是什么？（他真正需要的）
5. 什么事会让他动摇？（触发事件的候选）
6. 他低谷时的样子是什么？（具体场景）
7. 谁跟他最像但选了不同的路？（镜像配角）
8. 他有什么话永远不会说出口？
9. 他最强的能力和最大的缺陷有什么关联？
10. 故事结束时，他变了什么？没变什么？
```

### 6.2 创建配角时必回答的 5 个问题

```
1. 这个配角的 Want 是什么？（和主角的 Want 是冲突还是协同？）
2. 他对主角的功能是什么？（催化剂/镜像/阻碍/揭示）
3. 他的致命缺陷是什么？（不需要和主角一样深刻，但不能没有）
4. 他平时说话是什么风格？（用一句典型台词来定义）
5. 如果主角不在场，他在做什么？（配角有自己的生活，不是NPC）
```

## 七、路人级角色简易卡

### 7.1 适用场景

并非每个出场角色都需要完整人物卡。满足以下条件的角色属于**路人级角色**，使用简易卡即可：
- 有名有姓（非通用称谓）
- 仅出场 1-2 句台词 / 1-2 段描写
- 不推动主线剧情（仅为场景氛围、功能性出场）

### 7.2 简易卡模板

路人级角色只需填写 **6 个字段**：

| 字段 | 说明 | 示例 |
|------|------|------|
| 姓名 | 角色名字 | 王老六 |
| 性别 | 男/女/其他 | 男 |
| 年龄 | 大致年龄段 | 五十出头 |
| 身份 | 在故事中的身份/职业 | 茶馆老板 |
| 出场场景 | 在哪个场景/哪章出现 | 第3章 茶馆偶遇 |
| 对话风格 | 一句话概括说话方式 | 市井腔，话多爱唠叨 |

> 📋 完整模板文件：`templates/人物简易卡模板.md`

### 7.3 简易卡 vs 完整卡

| 对比维度 | 简易卡（路人级） | 完整卡（核心/次要角色） |
|---------|----------------|---------------------|
| 字段数 | 6 个 | ≥12 个 |
| 适用角色 | 仅出场 1-2 句 | 有剧情线 / ≥3 句台词 |
| 是否必需 | 是（或人物总表注册） | 是 |
| 存储位置 | `02-设定文档/人物库/` | `02-设定文档/人物库/` |
| 能否升级 | 可以——当后续章节中该角色戏份增加时，将简易卡扩展为完整卡 | — |

### 7.4 创建简易卡的决策树

```
角色出场 →
  ├─ 仅有 1-2 句台词/动作，不推动主线？
  │   ├─ 有名有姓？ → 创建 简易卡 或 在人物总表中注册一行
  │   └─ 无名字（通用称谓如「路人」「店小二」）？ → 无需注册
  │
  └─ ≥3 句台词 或 推动主线？
      └─ 创建 完整人物卡（至少 12 字段）
```

### 7.5 人物总表注册（比简易卡更轻量）

如果角色戏份极少且未来大概率不升级，亦可在「人物总表」中注册一行代替简易卡：

```markdown
| 姓名 | 性别 | 年龄 | 身份 | 出场章节 | 备注 |
|------|------|------|------|---------|------|
| 王老六 | 男 | 五十出头 | 茶馆老板 | 第3章 | 路人级，简易卡备选 |
```

> ⚠️ 注意：人物总表注册一行即可通过 novel-review 的人物一致性检查，等级等同于简易卡。但推荐优先使用简易卡，因为对话风格字段对 OOC 检测有参考价值。

### 7.6 审查引用

人物一致性检查（novel-review §一点五）会检查路人级角色的注册状态：
- 有简易卡 或 人物总表注册 → ✅ 通过
- 两者都没有 → ⚠️ 二级问题「未注册角色(路人级)」

## 注意事项

- **弧光不是「变强」**：从练气期到筑基期是实力变化，不是人物弧光。弧光是内在价值观的变化。
- **缺陷不能太容易改**：如果人物在第 50 章意识到了缺陷，第 51 章就改了——前面的 50 章白写了。改变需要时间。
- **配角不是工具人**：每个配角要有自己的 Want——哪怕只有一句话。他们的行动逻辑应该自洽。如果这个配角的全部存在意义就是帮助主角或阻碍主角，你就写了一个工具人。
- **潜台词≠故弄玄虚**：不要每句话都藏着巨大的秘密。日常对话可以有轻松的潜台词（调侃、试探、回避），不是只有「我隐藏了一个惊天秘密」才有潜台词。
- **这些东西不是写在大纲里就行**：致命缺陷、Want/Need、弧光——这些必须在正文中通过行动和对话呈现，不能靠旁白解释。
